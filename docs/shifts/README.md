# The four shifts

Four changes that follow from the bottleneck moving. None of them are about tooling.

Each is written **failure mode first** — what breaks if you don't make it — because that's
how you'll recognise whether it applies to you. Start with the one you recognise.

| # | Shift | The failure it prevents |
|---|---|---|
| 1 | [Split the role before it splits itself](01-split-the-role.md) | Building crowds out deciding, invisibly, in the same person |
| 2 | [Instrument adoption on day one, not month six](02-instrument-adoption.md) | Silence read as success |
| 3 | [Make the disagreement visible before you make the thing](03-surface-disagreement.md) | Six weeks spent discovering a disagreement that existed on day one |
| 4 | [Freeze the surface so people can build habits](04-freeze-the-surface.md) | A tool that enables the whole job and is worth zero |

They are ordered by when they bite, not by importance. 1 and 3 are the ones with teeth;
2 and 4 are the ones people actually implement first because they're cheaper.
