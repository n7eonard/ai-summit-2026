# The shifts

Changes that follow from the bottleneck moving. None of them are about tooling.

Each is written **failure mode first** — what breaks if you don't make it — because that's how
you'll recognise whether it applies to you. Start with the one you recognise.

| # | Shift | The failure it prevents |
|---|---|---|
| 1 | [Split the role before it splits itself](01-split-the-role.md) | Building crowds out deciding, invisibly, in the same person |
| 2 | [Instrument adoption on day one, not month six](02-instrument-adoption.md) | Silence read as success |
| 3 | [Make the disagreement visible before you make the thing](03-surface-disagreement.md) | Weeks spent discovering a disagreement that existed on day one |
| 4 | *slot open* — see below | — |

1 and 3 are the ones with teeth. 2 earns its place through the judge-and-party link: when the
builder and the decider are the same person, nobody is positioned to disbelieve the builder's
enthusiasm.

## The fourth slot is open

**Decided 2026-08-24:** *Freeze the surface so people can build habits* is **dropped**. It was
true and useful but it was change management — it would have sat just as well in a talk about
something else, which is exactly what the relevance filter is there to catch.

The retired shift is kept at [`04-freeze-the-surface.md`](04-freeze-the-surface.md). Nothing in
it is wrong; it just isn't this talk. Some of it may be reusable in whatever fills the slot.

**What should fill it.** The strongest candidate isn't a new idea — it's the half of the
vantage that isn't written down yet: the contrast with twelve years where deciding and
building were separated, and what specifically used to force the deciding to happen.
→ [`../../meta/open-questions.md`](../../meta/open-questions.md) Q24 and Q26.

The abstract published by the conference promises "4 shifts". Either the slot gets filled or
the talk delivers three and doesn't draw attention to the arithmetic — three that all land
beats four where one is off-topic.
